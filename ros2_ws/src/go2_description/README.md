# Go2 description

The URDF and DAE meshes in this package are vendored from
[`Unitree-Go2-Robot/go2_description`](https://github.com/Unitree-Go2-Robot/go2_description)
at commit `8bd6717ff0c7b5ca388c0e10e426dd9ad873ceaf` (branch `humble`).
See [LICENSE](LICENSE) for the upstream license.

The FAST_LIO launches supply the body and lidar transforms. This package supplies
the `base_link` robot geometry and leg links for RViz.
